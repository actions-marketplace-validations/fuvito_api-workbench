# Clear Signal — Frontend

React 19 + TypeScript 7 + Vite 8 frontend for the Clear Signal desktop application. Runs inside a [Wails](https://wails.io) shell; communicates with the Go backend exclusively through Wails IPC bindings.

## Development

Start the full app in dev mode (hot reload for both Go and TypeScript):

```bash
cd ../wails
wails dev
```

For frontend-only iteration (no Go backend — uses mocked IPC):

```bash
pnpm dev
```

The mock bridge at `src/lib/bridge.ts` controls what the frontend receives when no real backend is running.

## Tests

```bash
# Unit tests (Vitest + React Testing Library)
pnpm test

# Watch mode
pnpm test:watch
```

E2E tests live in the sibling `../e2e/` package (Playwright).

## Lint

```bash
pnpm lint
```

## Build

The frontend is not built directly — `wails build` from `../wails/` builds everything and embeds the frontend output. The Vite `outDir` is set to `../wails/frontend/dist/` for this reason.

## Structure

```
src/
├── components/     # UI components (RequestEditor, ResponseViewer, Sidebar, …)
├── hooks/          # React hooks (useTabsState, useWorkspace, …)
├── lib/            # Utilities — bridge wrappers, HTTP utils, curl import, tab state
└── types.ts        # Shared TypeScript types (KVPair, BodyState, AuthState, …)
```

## IPC

All calls to the Go backend go through `src/lib/bridge.ts`, which wraps the Wails-generated bindings. The generated `wailsjs/` directory is gitignored — it is regenerated by `wails dev` or `wails build`.
