# ApiDesk — Audit Checklist

## 🐛 Bugs

- [x] **Close Workspace doesn't close tabs on Windows** — path prefix check used `/` separator but Windows paths use `\`. Fixed: normalize both sides to forward slashes before comparing.
- [x] **`Ctrl+O` shortcut shown in File menu but never fired** — keyboard handler was missing the `o` case. Fixed.
- [x] **Stopping demo server loses your previous workspace** — `workspacePath` is cleared to `''` unconditionally on stop. If a workspace was open before the demo, it's gone. Fixed: `DemoService` saves/restores `prevWorkspace`/`prevEnvPath`; frontend calls `refreshWorkspace()` after stop.
- [x] **Dirty-tab dot in sidebar only reflects the active tab** — `isDirty` passed to `WorkspacePanel` is always `isTabDirty(activeTab)`. Other open/dirty tabs show no dot next to their file. Fixed: pass a `Set<string>` of dirty file paths; each tree row checks its own path.
- [x] **Switching body type clears content silently** — accidentally clicking Raw when you have a JSON body written loses the content with no undo or confirmation. Fixed: content is preserved when switching between non-none types.
- [x] **Status code 0 (network error) looks ambiguous** — shows `0` in the status bar with no colour; could be confused with a real response. Fixed: status bar shows "Network Error" in red when `response.error` is set.
- [ ] **Copy response copies raw body even in Pretty mode** — `handleCopy` in `ResponseViewer.tsx` always writes `response.body`; in Pretty mode the displayed text is the formatted `prettyBody` but the clipboard gets the raw string. Fix: copy `bodyText` (the currently displayed representation) instead.
- [ ] **Proxy URL is not validated before saving** — `SettingsPanel` accepts any string for Proxy URL; an invalid URL is stored and silently fails at request time rather than being caught early.
- [ ] **TimingBar minimum-width guard can push total past 100%** — each segment enforces `Math.max(…, 1%)` to stay visible; with many sub-millisecond segments the bar's total exceeds 100% and the last segment is clipped by `overflow-hidden`. Fix: distribute the minimum pixels without inflating percentage widths.

## 🔍 Missing / Expected Features

- [x] **No way to cancel an in-flight request** — once Send is hit, there is no Cancel button. Fixed: Send button becomes Cancel while loading; `CancelRequest()` on Go side cancels the HTTP context.
- [ ] **History entries only restore method + URL** — headers, auth, body, and query params from the original request are not stored or restored. At minimum add a tooltip clarifying this.
- [x] **No way to clear history** — the list grows unbounded. Fixed: "Clear history" link appears in the history tab header when there are entries.
- [x] **Form URL-encoded body is a plain textarea** — Fixed: `KeyValueEditor` row editor used instead, with encode/decode on change.
- [ ] **No multipart/form-data body type** — file uploads are impossible from the UI despite the demo server supporting them.
- [ ] **Variable value tooltip / preview** — hovering `{{baseUrl}}` in the URL bar should show what it resolves to from the active environment. No warning either when a `{{variable}}` has no match in the active environment.
- [x] **No "Copy response body" button** — Fixed: Copy icon added to response status bar; shows checkmark for 1.5s after copy.
- [x] **No "View raw" toggle in response** — Fixed: Raw/Pretty toggle button added to response status bar; raw mode skips pretty-printing and syntax highlighting.
- [ ] **No per-request timeout override** — only a global default; no way to override for a single slow endpoint.
- [x] **No search / filter in the workspace file tree** — Fixed: search input at top of file tree; filters nodes and their parent folders in real time.
- [x] **OpenAPI import only from file, not from URL** — Fixed: "Import OpenAPI from URL…" in File menu; fetches spec and detects JSON/YAML from Content-Type or extension.
- [ ] **No drag-and-drop in the file tree** — can't move a request between folders.
- [ ] **No mass-enable/disable for headers and query params** — toggling all rows requires clicking each checkbox individually; a "toggle all" button would save time for requests with many headers.
- [ ] **Timing breakdown hidden on network errors** — `ResponseViewer.tsx` only shows the timing bar when `!response.error`; DNS and connect times are most useful precisely when a request fails.
- [ ] **Workspace tree expand/collapse state resets on refresh** — `TreeNode` stores `expanded` in local React state; every workspace refresh (save, rename, import) collapses all folders back to their defaults.

## ⚠️ Inconsistencies / Polish

- [x] **Snippet auto-copy silently overwrites clipboard** — Fixed: removed the `useEffect` auto-copy in `SnippetButton.tsx`; clipboard is only written when the user clicks Copy.
- [x] **Environment editor pencil tooltip is misleading** — Fixed: tooltip now reads "Create environment" when no env is active.
- [x] **Bearer / API-key tokens are plain text** — Fixed: `SecretInput` component wraps bearer Token and API Key Value fields with `type="password"` and an Eye/EyeOff reveal toggle.
- [x] **`Ctrl+Enter` fires even when the find bar input is focused** — Fixed: keyboard handler guards `Ctrl+Enter` with `activeElement instanceof HTMLInputElement || HTMLTextAreaElement` check.
- [x] **`Ctrl+Enter` to send is undiscoverable** — Fixed: Send button now has `title="Send (Ctrl+Enter)"`.
- [x] **No "Save As" option** — Fixed: `handleSaveAsRequest` added; "Save As…" in File menu always opens a save dialog regardless of current file path.
- [x] **Dirty-tab close button always hidden until hover** — Fixed: close button is `opacity-100` on dirty tabs; `opacity-0 group-hover:opacity-100` only for clean tabs.
- [x] **Deleting a non-empty folder silently fails** — Fixed: Go `DeleteFolder` retains emptiness guard; context menu shows Delete disabled with label "Delete — folder not empty" when children exist; hover-icon Delete only appears for empty folders.
- [x] **Demo port pill is not interactive** — Fixed: `Demo :8080` is now a button that copies `http://localhost:<port>` to clipboard on click.
- [x] **No "Reset to defaults" button in Settings** — Fixed: `SettingsPanel` gains `onReset` prop; "Reset to defaults" button added to footer; wired via `handleResetSettings` in `App.tsx`.
- [ ] **Tab method badges truncate mid-word** — `tab.method.slice(0, 3)` renders POST as "POS", PATCH as "PAT", DELETE as "DEL"; these are not standard abbreviations. Use recognised short forms: POST→"PST", PATCH→"PCH", DELETE→"DEL" or widen the minimum tab width slightly.
- [ ] **Copied-to-clipboard toast vanishes in 1.5 s** — both the response body copy and the snippet copy use a 1 500 ms timeout; on larger screens or slow blink rates this is easy to miss. 2 000–2 500 ms is more conventional.
- [ ] **Font size change doesn't update snippet dialog live** — `SettingsPanel` calls `onPreview` which sets the CSS variable `--font-size-code`, but the `SnippetButton` dialog is mounted before the preview fires; the code block renders at the old size until the dialog is closed and reopened.
- [ ] **Settings panel doesn't mark non-default values** — there is no visual cue (e.g. a dot or italic label) showing which settings differ from defaults; after clicking Reset the user cannot see what changed.
- [ ] **"Open in Explorer" errors are silently swallowed** — `WorkspacePanel.tsx` calls `openInExplorer(path)` but discards the returned error string; if the system command fails the user gets no feedback.
- [ ] **Paste URL with query string gives no feedback if parsing fails** — `RequestEditor.tsx` catches the parse error and falls through to the raw URL silently; the user doesn't know their `?page=1&limit=20` was not extracted into the Params tab.
- [ ] **Duplicate environment button is missing** — `EnvironmentEditor` lets you create or delete environments but not duplicate one; creating a staging/production variant of an existing environment requires rebuilding it from scratch.
