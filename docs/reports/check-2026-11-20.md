## Verified, no change needed

- **`--read-only` really sends nothing else.** The runner and the negative-probe runner both honour it, and the page passes `ReadOnly: !AllowWrites`. A closed-port run showed the POST and DELETE operations as SKIP.
- **Remote base URL guard.** `IsLocalBaseURL` accepts only `localhost`, `127.0.0.1` and `::1` by exact hostname, so `localhost.evil.com` is remote. The page also guards a base URL that came only from the spec's `servers`.
- **Circular schemas.** A `Node` that references itself through `parent` and `kids` generates in under a second and does not hang or overflow; the cyclic fields become placeholders.
- **Not-sent operations.** An unresolved `{{id}}` blocks the operation, counts it as failed and gives one aggregated advice line (B-009 works as designed).
- **Missing spec file** exits with a clear message and code 2.
- **End to end against the example server.** `conform --negative --coverage --explain` passes 2 operations and 4 probes, with 100% coverage.
- **Environment memory per workspace.** Temporary demo and conformance workspaces are not remembered (`rememberEnvironment`) and are not added to recent workspaces; the selection is stored relative to the workspace.
- **Shared code.** The CLI, MCP and desktop all go through `application.RunConformance`; the timeout default lives in one constant. Parity tests pass.
- **Catalog.** `what-we-check.md` is checked by tests (`what_we_check_doc_test.go`, `what_we_check_test.go`). Its known gaps match what I saw (extra properties, `format: email`, non-JSON bodies, undeclared headers).
- **Docs reorganization.** All relative links resolve; `CLAUDE.md` and `docs/README.md` describe the new layout.
- **Generated bindings.** The only working-tree changes are line endings in six `wailsjs` files (no content change).

## Known limits and open points

- **Format and constraint gaps** are listed in the catalog (CS-GAP-001 to 009); they are known, not new.
- **The bodystub generator** still produces required-only bodies (decided in B-003); optional fields are not exercised.
- **Line endings:** 72 Go files are CRLF in the working tree and 3 are mixed. Git normalises them; `.gitattributes` with `* text=auto` would stop the noise.
- **Backlog:** findings 2, 3, 4 and 11 are not on it yet.
